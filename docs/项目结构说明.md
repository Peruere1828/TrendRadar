# 项目结构说明

本文说明当前代码和目录职责。

## 总览

```text
TrendRadar/
  trendradar/              # 主程序包
  mcp_server/              # MCP 查询分析服务
  config/                  # 运行配置和提示词
  docker/                  # Docker 镜像、Compose 和入口脚本
  docs/                    # 文档和静态说明页
  output/                  # 运行产物，本地生成
  _image/                  # 文档图片素材
```

## 主流程

```text
python -m trendradar
  -> 加载 config/config.yaml 和环境变量
  -> 按 timeline.yaml 判断当前调度动作
  -> 抓取热榜和 RSS 数据
  -> 执行关键词筛选或 AI 兴趣筛选
  -> 按配置抓取命中文章正文
  -> 生成报告
  -> 推送通知
  -> 写入 output/
```

常用命令：

```bash
python -m trendradar
python -m trendradar --show-schedule
python -m trendradar --doctor
python -m trendradar --test-notification
```

## mcp_server/

```text
mcp_server/
  server.py                # MCP HTTP/stdio 服务入口
  services/                # 数据、解析、缓存服务
  tools/                   # 暴露给 AI 客户端的工具
  utils/                   # 校验、日期解析、错误类型
```

MCP 读取主流程产生的数据，用于查询、搜索、文章读取、趋势分析、状态检查和部分管理操作。MCP 不负责定时抓取和通知发送。

## config/

```text
config/
  config.yaml              # 主配置
  timeline.yaml            # 调度规则
  frequency_words.txt      # 关键词分组
  ai_interests.txt         # AI 兴趣描述
  ai_analysis_prompt.txt   # AI 分析提示词
  ai_translation_prompt.txt
  ai_filter/               # AI 筛选提示词
  custom/                  # 自定义扩展配置
```

`config/config.yaml` 覆盖这些主要配置：

```text
platforms                  # 热榜平台
rss                        # RSS 源
filter                     # 筛选模式
notification               # 通知渠道
storage                    # 本地/远程存储
article_content            # 正文抓取
ai                         # AI 模型和接口
ai_analysis                # AI 分析
ai_translation             # AI 翻译
```

## docker/

```text
docker/
  Dockerfile
  Dockerfile.mcp
  docker-compose.yml
  docker-compose-build.yml
  docker-compose.server.yml
  entrypoint.sh
  manage.py
  .env.example
```

常用命令：

```bash
cd docker
docker compose up -d
docker compose -f docker-compose-build.yml up -d --build
docker compose -f docker-compose.server.yml up -d
```

`docker/.env` 是本地私有环境变量文件，由 `docker/.env.example` 复制得到，不提交到仓库。

## output/

`output/` 是运行产物目录，包含 SQLite 数据库、HTML 报告、RSS 数据和其他生成文件。该目录不提交到仓库，部署时应挂载或持久化。

常见结构：

```text
output/
  news/
  rss/
  html/
```
